
# Zion SmashBoard 🏸

A minimal badminton tournament manager built using Streamlit.

## Features

- Password protected login
- Player management
- Random doubles pair generation
- Automatic fixture generation
- Daily leaderboard
- Overall leaderboard
- Match history
- Winner tracking
- Password reset
- Mobile-friendly UI

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Default Password

zion123

Change it from Settings after login.
